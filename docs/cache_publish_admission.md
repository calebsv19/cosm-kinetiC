# Scene-cache publication path admission

Main Edit validates cache run IDs as bounded single components at explicit,
default-root and environment entrypoints. Publication preflights project/source,
all four replacement slots and all three manifest destinations before destructive
overwrite. Linked/special paths, hardlinked leaves, protected system roots,
source/replacement overlap, excessive depth, entries and metadata byte budgets
are refused. Ten native fixture methods and the actual isolated scene-cache status
contract pass. Fixtures use controlled bytes, not numerical CFD qualification.

The original remove-before-copy sequence remains. These static admission checks
have no cooperative transaction lock or complete path-race confinement. They do
not provide coherent multi-file replacement, interruption recovery, disk quotas,
I/O deadlines or archive-backed retirement. Canonical has not adopted this work.
