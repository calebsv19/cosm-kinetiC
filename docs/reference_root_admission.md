# Reference preparation path and source admission

All 194 identified reference wrappers now use the standard-library-only bootstrap
helper to admit paths before source freezing or factor compilation. The helper
must itself be a bounded regular checkout file with no linked path components.
The frozen helper remains part of source identity and numerical supervision.

A selected DATA root must stay in a checkout-owned legacy `build/c3d-*/<family>`
namespace or a nested `data/experiments/<family>/<runs>` namespace. Absolute paths
without parent traversal are required. Linked path components, protected root
selection and non-directory parents hold before generated allocation. This does
not migrate historical build evidence or claim all configurable lifecycle roots
are reconciled.

Before creating missing source directories or copies, preparation hashes regular
checkout dependencies under a 64 MiB per-file streaming bound, admits the selected
run and supervisor namespace, and validates all existing retained source copies.
Namespace inspection bounds traversal at 100,000 entries and depth sixteen, and
rejects linked/special entries. Create-only freezing uses nofollow regular source
reads, a byte bound, fsync, digest and before/after descriptor/path witnesses.
Failed or interrupted copies remain held; they are not overwritten or deleted.
Matching frozen files retain their inode and bytes on reuse. A consistency-family
runner source snapshot is now retained alongside the other runner snapshots.

Six legacy manifests repeated a dependency filename. Their declarations were
deduplicated in first-occurrence order. All 194 ordered unique source inventories
and solver/compiler command assignments compared unchanged. Source hash mappings
remain the same for identical helper bytes; the updated helper itself correctly
creates a new source-identity partition.

Behavior checks exercise linked roots and linked checkout sources across every
family, protected/outside/traversal roots, linked run/source/supervisor directories,
changed frozen copies, special files and unchanged reuse. Family regression uses
controlled native factor libraries and synthetic numerical probes. It does not
qualify the real CFD factor ABI, numerical accuracy or installed products.

The preflight/witness protections are for trusted cooperative local operation.
They do not establish a descriptor-confined sandbox against hostile concurrent
ancestor swaps, authenticated process ownership, complete namespace locks,
aggregate hash quotas, transitive toolchain/config provenance or complete writer
coverage. Those requirements, interruption recovery, retirement/pruning and
canonical adoption remain open. No original evidence was pruned or migrated.
